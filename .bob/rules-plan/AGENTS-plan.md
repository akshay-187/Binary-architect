# Plan Mode Rules

Plan Mode is read-only. No file edits are allowed.

- Explore using `docs/PROJECT_MAP.md` first — do not grep blindly.
- Output a numbered plan covering: scope, files touched, risks, test
  strategy, and commands to run.
- Flag any assumptions explicitly.
- Keep the plan under 80 lines.
- Reference files by path only — do not quote their contents.
- End every plan with: "Reply APPROVE to proceed, or REVISE to adjust."
