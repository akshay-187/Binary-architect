# /report

Generates a review-ready report and writes it to
`bob_sessions/issue-XX-report.md`.

## Contents

1. Issue summary.
2. Root cause.
3. Files changed.
4. Patch summary.
5. Tests added.
6. Validation results (raw output).
7. Risk level: Low, Medium, or High.
8. Assumptions made.
9. Points for human review.
