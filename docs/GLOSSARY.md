# Glossary

| Term | Definition |
|------|------------|
| Issue | A bug report describing a problem in the target repository |
| Plan | A proposed approach to fixing an issue, pending approval |
| Patch | The minimal code change that resolves an issue |
| Regression test | A test that fails before a patch and passes after it |
| Gate | A point in the pipeline requiring human approval before continuing |
| Session | One continuous IBM Bob working period on a task |
| Investigation | The process of analysing an issue to find its root cause |
| Approval | Explicit human sign-off at a gate |
| Benchmark | A fixed set of issues used to evaluate PatchPilot's performance |
| Bob session report | An exported record of a Bob session, required for hackathon submission |
