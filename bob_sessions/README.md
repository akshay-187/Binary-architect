# Bob Sessions

This folder contains exported IBM Bob session reports, required for
hackathon submission.

## How to export

- From the Bob UI: use the history panel's export option.
- From the CLI: use the Bob CLI's session-export command.

## Naming convention

- `issue-XX-<topic>.md` for per-issue session reports.
- `YYYY-MM-DD-HHMM.md` for `/handoff`-generated session exports.

## Screenshots

Session summary screenshots go in `bob_sessions/screenshots/`.
